# CPIのお弁当・バー構想 サイト提案

2026-10-08。ユーザー指定のScrolltideを参照した飲食店サイト。最新の訂正は「お弁当屋。バーも検討中」。お弁当を主役に変更し、バーは営業を断定しない独立した構想として掲載。正式店名は未確定のため「CPIのお弁当」は提案用のブランド表記です。

## ページ

- 動的版: `https://acy05.github.io/cpi-corporate-site/restaurant/`
- 控えめ版: `https://acy05.github.io/cpi-corporate-site/restaurant/calm/`
- 比較入口: `https://acy05.github.io/cpi-corporate-site/`

ローカル: リポジトリ直下から `python3 -m http.server 4174 --bind 127.0.0.1` を実行し、同じパスをローカルホストで表示。

`restaurant/index.html` は新しい動的版、`restaurant/calm/index.html` は以前の動的版の演出を保持した控えめ版です。2つのHTMLを独立管理します。今回の業態訂正で両方の画像・コピー・構想紹介を更新したため旧HTMLとの完全一致検査は廃止。`node tools/build-restaurant.mjs` で相対参照、演出モード、古い定食屋表記の残存を検査します。

共通CSS/JSに加えて新動的版だけが `assets/cinematic.css` / `assets/cinematic.js` を読み込みます。外部JavaScriptライブラリ・解析・フォーム送信先はありません。

## 表現と動き

- Scrolltideの公開トップとNOPAL紹介を実ブラウザで確認。追加指示でNOPALの被写体が浮き上がり傾くプレビューを再確認し、一皿の切り抜き・回転・接近・接写切替として独自実装。テンプレート・有料プロンプト・写真・コードは転用していません。
- 参考: https://www.scrolltide.co/ および https://www.scrolltide.co/templates/nopal
- 動的版（改訂）: 切り抜いた一皿の登場・回転・最大1.85倍の接近、左右へ抜ける見出し、円形のマスクが広がる料理の接写、朱赤の最終シーン。スクロール量に連動する3場面と、各場面へ移動するボタンを実装。実写動画の再生ではなく、写真・文字のレイヤーをスクロール量で変形する演出です。
- 続く料理カードは、縦スクロールに合わせて横へ流れ、位置に応じて3D傾斜。キーボードで次のカードに移ると見える位置へ移動。料理背景の大きな接近・移動、見出しの動き、流れる文字も実装。
- 控えめ版（改訂）: ユーザーの指示で、以前の動的版をそのまま移行。元の固定ヒーロー、最大12%の写真ズーム、印の傾き、文字帯、フェード、背景移動を維持しています。初回の弱いフェードだけの版は今回の2案には使っていません。
- 両方とも停止・再生ボタン。端末の `prefers-reduced-motion: reduce` ではアニメーション・スムーススクロール・固定ヒーローを無効にするCSS/JSを実装。
- 前回のCPI Reference Serif/Sansを再利用。日本語の見出しはOS明朝体にフォールバック。
- メニュータブは左右矢印/Home/Endに対応。詳細はネイティブdialog、Escapeで閉じ、開いたボタンにフォーカスを戻す。

## 確定事項と提案

- 確定: 株式会社CPI、業態の意向は「お弁当屋」。バーは検討中。共有された住所は会社所在地としてのみ記載。
- 仮のブランド表記: CPIのお弁当。
- 提案: 唐揚げ弁当、生姜焼き弁当、単品唐揚げ、文章、付け合わせ、写真。生姜焼き写真はメインのおかずの接写です。
- 未確定: 正式店名、実店舗所在地、営業時間、定休日、電話・予約先、価格、提供品目・アレルギー情報。
- 予約・送信が完了したと誤認するフォームは設置していません。店情報は準備中の表示です。
- 提案ページにはnoindexを設定。これは非公開化ではありません。
- AddnessでCPIのゴール・ナレッジを検索した結果、該当なし。無関係なゴールには記録していません。
- Lazywebのローカル検索スキルを確認しましたが、現在の接続に対応ツールがなく実検索はできていません。参考サイトを直接確認しました。

## 画像

組み込みimagegenで3点を新規生成し、改訂時に1点の透明切り抜きを追加。1536×1024 WebPとして配置。実物の料理写真ではありません。元画像は生成場所に保持し、配信用WebPのみリポジトリに含めています。

- `assets/hero.webp`: 木のテーブルに唐揚げ、ごはん、味噌汁、小鉢を並べた定食。左側に見出し用の余白を置く横長写真。
- `assets/karaage.webp`: 香ばしい唐揚げとレモン、キャベツの接写。
- `assets/shogayaki.webp`: 豚肉と玉ねぎの生姜焼きの接写。
- `assets/plate.webp`: 元の定食写真を参照して一皿を透明背景に切り抜いた素材。RGBA・透明ピクセルの存在を確認。新動的版の浮かぶ一皿に使用。

生成プロンプト全文は `IMAGE_PROMPTS.md` に記録しています。

## 検証

改訂版は実ブラウザでPC幅1097px、スマートフォン幅390px・320px、タブレット幅768pxを確認。3場面が切り替わること、接写シーンのopacity=1、最終シーンのopacity=1、横流れのカードが中央に移ること（2枚目で約471pxの横移動）、キーボードのフォーカス、停止時にカードが手動横スクロールで閲覧できることを確認しました。料理詳細・メニュータブ・モバイルメニュー・Escape・フォーカス復帰・画像読込を確認。横方向のはみ出しは修正後に0件、ブラウザエラーログ0件、入口と2案のローカル相対参照欠落0件。

以前の演出移行時は控えめ版を元の動的版と照合済み。今回のお弁当改訂では画像・文章・ヒーロー配置を更新し、従来のズーム・文字帯・フェードを維持。PC / 390pxで新しい写真と詳細ダイアログ、メニュー開閉、バーへの移動、横はみ出しなしを確認しました。

端末の「視差効果を減らす」設定そのものの切替は行っていません。該当メディアクエリ実装の確認と停止ボタンによる実動作検証を行っています。
