# 株式会社CPI サイト提案集

## 最新改訂：物流コーポレートサイト / お弁当とバー構想

- `logistics/`: 新規の物流事業コーポレートサイト。会社概要、事業紹介の構成案、相談の流れ、未接続のお問い合わせ窓口。
- `restaurant/` / `restaurant/calm/`: お弁当屋への訂正を反映。バーは出店未確定の独立した構想として掲載。同一店舗の昼夜営業とは断定しない。
- 会社名・所在地以外の代表者、設立、車両、許認可、配送条件は未確認として表示。架空の実績は掲載しない。
- `index.html`: 物流・飲食の選択画面。初期のコンサルティング向けコーポレート案は折りたたみ内で保持。
- `node tools/build-restaurant.mjs`: 4ページの相対参照、両飲食版の演出モード、旧業態文言の残存を検証。
- 新しい画像のプロンプト・保存先: `IMAGE_PROMPTS_2026-10-08.md`。

## 飲食店サイト（2026-10-08追加）

- `restaurant/`: 唐揚げ弁当を主役にした動的版
- `restaurant/calm/`: 同一内容のアニメーション控えめ版
- `restaurant/README.md`: 仕様・参考・検証・未確定情報
- `node tools/build-restaurant.mjs` で両版のファイル参照を確認。2案は独立したHTMLとして保持。

2026-10-08の追加指示により、以前の動的版をそのまま控えめ版に変更し、新しい動的版はスクロールに連動する一皿の回転・接近・3場面切替・横流れの料理カードとして再制作しました。

既存のコーポレートサイトは以下のURLに保持しています。

- `static/`: アニメーションなし
- `motion/`: アニメーションあり
- `index.html`: 2案の選択画面

## フォント

直近の再現工程で作成した `Yahata Reference Serif` 系ファイルを、案件内の `CPI Reference Serif` としてローカル配信しています。これはLibre Baskerville由来の英数字・欧文表示用です。日本語はOSの明朝体（ヒラギノ明朝／游明朝）へフォールバックし、参考画像に合わせて字幅・太さ・行間をCSSで調整しています。

## 公開前に必要なもの

- 実際の代表者・スタッフ・オフィス・建物写真への差し替え
- 代表者名、設立年、連絡先、サービス詳細等の正式原稿
- フォーム送信先、プライバシーポリシー、ドメイン・サーバー設定
- 実機Safariを含む公開環境QA
