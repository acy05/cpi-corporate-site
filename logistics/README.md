# CPI物流コーポレートサイト

飲食版から独立した静的HTMLサイト。既存のstatic/、motion/は変更せずに保持。

- 深い紺・白・ライム色。物流のヒーロー、サービス構成案、安全・連絡・関係性の姿勢、相談フロー、会社情報、窓口準備中の表示。
- 配送・定期・スポットは掲載構成案であり、実際のサービス提供を未確認のまま保証しない。
- 会社名・会社所在地はユーザー提供。代表者・設立・許認可・車両・エリア・連絡先は未確認。
- フォーム、電話リンク、メールリンクを捏造しない。送信機能は未接続と明示。
- noindexは検索登録抑制であり非公開ではない。
- 写真の小さな移動のみ。停止ボタンはPCではナビの補助操作、スマホではメニュー内に配置。停止時は写真の移動とスムーズスクロールを停止。reduced-motion対応。本文をフェードで隠さない。
- 2026-10-08 v3：重複住所と基本情報帯を整理し、住所は会社表の1か所へ統合。制作向け説明は下部の開閉注記にまとめ、各章には案であるラベルを残す。事業は短い一覧、方針は番号付きリストに変更。問い合わせの準備中説明も簡潔にした。
- 日本語・英数字の本文はNoto Sans JPを自サイト配信。400/500/700を使い分ける。ページの文字と動的ラベルを含むサブセットを生成し、文字漏れなしを検査。ブラウザFontFaceSetでloadedと各太さのcheck=trueを確認。出典・OFL・更新手順はassets/fonts/README.md。既存の他サイトのフォントは変更しない。
- PC1280×900、スマホ390×844・320×740、タブレット768×1024で横はみ出しなし。390pxの全体高は前版約6007px→約3991px（最後の注記短縮前の測定、約34%減）。会社情報16px、スマホヘッダー社名12px。
- メニュー開閉・Escapeのフォーカス復帰、停止・スムーズスクロール停止、会社/事業/問い合わせへの移動を確認。JavaScript不実行のローカル派生QAでもナビゲーションを表示する設計。
- ローカル検証用のroot font-size:200%で320/390/768/1280pxの横はみ出しなし。ブラウザ自身のズームとは区別。QA用一時HTMLは確認後に削除。
- OGP・Twitter Card・canonicalを追加。共有画像は既存の生成イメージ。タグ検証と実ファイルの到達確認を行い、SNSサービス側のカード表示は未検証。
- 採点は暫定の自己レビューで、正式運用の完成や問い合わせ受付開始を意味しない。設計・表示の既知の修正項目と、ヒアリング後の事実確定を区別する。
- ブラウザ検証はデスクトップ内蔵ブラウザ。実機iPhone/Safariでの検証とOS reduced-motion設定自体の切替は未実施。
- 画像生成プロンプトはルートのIMAGE_PROMPTS_2026-10-08.md。
