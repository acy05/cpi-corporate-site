# CPI物流コーポレートサイト

飲食版から独立した静的HTMLサイト。既存のstatic/、motion/は変更せずに保持。

- 深い紺・白・ライム色。物流のヒーロー、サービス構成案、安全・連絡・関係性の姿勢、相談フロー、会社情報、窓口準備中の表示。
- 配送・定期・スポットは掲載構成案であり、実際のサービス提供を未確認のまま保証しない。
- 会社名・会社所在地はユーザー提供。代表者・設立・許認可・車両・エリア・連絡先は未確認。
- フォーム、電話リンク、メールリンクを捏造しない。送信機能は未接続と明示。
- noindexは検索登録抑制であり非公開ではない。
- フェード、写真の小さな移動、配送を抽象化したラインの動き。停止ボタンとreduced-motion対応。
- PC幅1097px / スマホ幅390pxで実表示確認。会社概要・問い合わせへのナビゲーション、スマホメニュー開閉、停止ボタン、画像読込、横はみ出しなしを確認。
- ブラウザ検証はデスクトップ内蔵ブラウザ。実機iPhone/Safariでの検証とOS reduced-motion設定自体の切替は未実施。
- 画像生成プロンプトはルートのIMAGE_PROMPTS_2026-10-08.md。
